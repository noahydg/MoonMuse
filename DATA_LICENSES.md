# Dataset licensing

The source code in this repository is licensed separately from the datasets used for training and evaluation. The source_data directory contains aggregate study results and numerical figure source tables. No third-party training dataset, processed event collection, model checkpoint, participant identifier, or individual listening-study response is included.

MoonMuse uses or supports event representations derived from EMOPIA, Pop1K7, and the HookTheory dataset released with Sheet Sage. Users must obtain each dataset from its official source and comply with its current licence and access terms.

HookTheory-derived event data are based on the dataset released with Sheet Sage under CC BY-NC-SA 3.0. Redistribution of derived HookTheory data must preserve attribution, non-commercial-use, and ShareAlike requirements. Such data are not covered by the repository's MIT software licence.

Do not scrape or bulk-download the current HookTheory website or API. Use the separately released research dataset and cite the corresponding dataset and publication.
